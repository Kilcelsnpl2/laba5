# Лабораторная работа № 5 — Вариант 10

Программа на C++, объединяющая четыре задания по строкам, векторам и словарям.

## Содержание

- **Часть A — Lowercase:** переводит латинские заглавные буквы в строке в строчные.
- **Часть B — Reverse vector:** выводит элементы целочисленного вектора в обратном порядке.
- **Часть C — Accumulate value:** прибавляет число к значению указанного ключа в словаре. Если ключа нет, его начальное значение равно `0`.
- **Часть D — Address book validation:** проверяет адреса электронной почты по условиям задания и выводит имена владельцев некорректных адресов.

## Требования

- Компилятор C++ с поддержкой C++11 или новее.
- Терминал или среда разработки для запуска программы.

## Компиляция

Если установлен компилятор `g++`, откройте терминал в папке с файлом и выполните:

```bash
g++ -std=c++11 -Wall -Wextra -pedantic Lab5_variant10.cpp -o Lab5_variant10
```

## Запуск

Linux/macOS:

```bash
./Lab5_variant10
```

Windows (MinGW):

```bash
Lab5_variant10.exe
```

При запуске программа предложит выбрать часть лабораторной:

- `1` — часть A;
- `2` — часть B;
- `3` — часть C;
- `4` — часть D.

После выбора введите данные для соответствующего задания.

## Примеры ввода

### Часть A — Lowercase

После выбора `1`:

```text
 Cat a12 dog Cat 
```

Ожидаемый результат:

```text
 cat a12 dog cat 
```

### Часть B — Reverse vector

После выбора `2`:

```text
7
-2 0 3 3 -1 4 0
```

Ожидаемый результат:

```text
0 4 -1 3 3 0 -2
```

### Часть C — Accumulate value

После выбора `3`:

```text
4
beta 2
alpha 5
beta 3
gamma -1
beta 4
```

Ожидаемый результат:

```text
alpha 5
beta 7
gamma -1
```

### Часть D — Address book validation

После выбора `4`:

```text
4
Anna
anna@example.org
Boris
boris.example.org
Chris
@example.org
Dana
d@x@y
```

Ожидаемый результат:

```text
Boris
Chris
Dana
```

## Обработка ошибок и ограничения

- Для некорректного ввода программа выводит `INVALID`.
- В части A длина строки не должна превышать 200 символов.
- В части B количество элементов должно быть от `0` до `100`, каждый элемент — от `-1000` до `1000`.
- В части C количество начальных пар должно быть от `0` до `100`, прибавляемое значение — от `-1000` до `1000`.
- В части D количество записей должно быть от `0` до `100`.
- В части D адрес считается корректным для условий этой лабораторной, если в нём ровно один символ `@`, перед ним и после него есть хотя бы по одному символу и в адресе нет пробелов.
